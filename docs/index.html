📚 Academic Tracker

論文・PDF・研究者・学会情報を一つの画面で整理し、CiNii連携とAI要約で先行研究の把握を支援するローカル研究支援アプリ。

解決したい課題

修士論文などの研究では、論文の検索結果・PDF・読書メモ・研究者や学会の情報が別々の場所に分散しがちです。その結果、文献の再発見や読了状態の把握、研究テーマとの関連づけに手間がかかります。Academic Tracker はこれらをローカルの一つのアプリに集約します。（課題は仮説であり、利用者調査での検証は今後の課題です。）

主な機能

📄 論文一覧

  • CiNiiから著者・キーワードで収集
  • 既読管理・メモ・DOI/抄録取得
  • PDF紐付けとAI要約
  • DBバックアップ・CSV出力

🧭 自分の論文から探す

  • 基準論文PDFからキーワード等を抽出
  • 候補をA〜Dで関連度評価し理由を表示
  • 選択候補を論文一覧へ統合

🔭 研究テーマ情報

  • テーマと検索語を登録
  • 論文・公的機関の報告を収集して要約
  • 出典付きの履歴を保存（7日間隔）

👤 研究者プロファイル

  • 専門分野・概念・所属学会の管理
  • AIによる情報取得と手動編集
  • 列配置による整理

🏛️ 関連学会アーカイブ

  • 研究者情報と双方向同期
  • 検討対象フラグ・メモ
  • 学会情報のAIリサーチ

⚙️ 著者・キーワード管理

  • 自動収集の対象を追加・削除

仕組み

利用者→Streamlit UI→SQLite / PDF保存

CiNii・Unpaywall・J-STAGE＋Google GenAI→収集・評価・要約

技術構成: Python / Streamlit / SQLite / requests / BeautifulSoup4 / pypdf / Google GenAI SDK

セットアップ

pip install streamlit requests beautifulsoup4 python-dotenv pypdf google-genai
copy .env.example .env   # APIキー等を設定
streamlit run app.py

Windowsでは start_app.bat でも起動できます。詳細は README を参照してください。
