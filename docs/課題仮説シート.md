# 課題仮説シート

> このシートは現行アプリの用途と既存の仕様コンテキストから整理した仮説です。利用者調査で検証された事実ではありません。

## 想定する課題

| 項目 | 仮説 |
|---|---|
| 対象者 | 修士論文等に取り組み、複数の学術文献・研究者・学会情報を追う学生・研究者 |
| 状況 | 論文を検索サービス、PDFをフォルダ、読書メモを別ファイルなどに分けて管理している |
| 困りごと | 文献の再発見、読了状態の把握、研究テーマとの関連づけ、研究者・学会情報の整理に手間がかかる |
| 影響 | 先行研究レビューの準備に時間がかかり、重要文献や次に確認する作業を見失いやすい |
| 現在の代替 | ブラウザーのブックマーク、表計算、PDFフォルダー、個別の検索サービスを併用している |

## 課題仮説

文献情報・PDF・読書メモ・研究者／学会情報を個別に管理することが、研究情報を再利用し、先行研究を継続的に整理する負担を増やしているのではないか。

## 解決仮説

ローカルの一つの画面に文献管理、PDF紐付け、研究者・学会整理を集約し、検索とAI要約を補助的に用いることで、研究者が関連情報を見つけて整理する負担を減らせるのではないか。

## 検証したいこと

- 利用者が文献を探し直したり、既読・未読を確認したりする時間が減るか。
- AI要約は原文の確認を助けるか。誤りの発見や修正に過剰な負担が生じないか。
- 研究者・学会情報の集約が、研究テーマの位置づけや発表先検討に役立つか。
- ローカル保存や外部AI送信に関する説明が利用者に理解され、安心して利用できるか。

## 検証方法の案

1. 想定利用者に現在の文献整理方法と困りごとを聞き、仮説の前提を確認する。
2. 少数の実際の研究タスクで、文献検索・記録・再発見の流れを観察する。
3. AI要約は原文との照合を含めて評価し、正確さと修正負担を記録する。
4. 検証結果をもとに優先機能と対象ユーザーを見直す。

## 未確認事項

- 課題の頻度・深刻度、対象利用者の規模
- CiNii中心の検索で必要な文献を十分に見つけられるか
- AI要約・プロフィール情報の精度と許容できる修正量
- クラウド公開、複数ユーザー、利用ログが必要か
- 研究データを外部AIへ送信する際の利用者の許容条件
